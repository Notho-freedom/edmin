# Edmin

School administration and management platform for educational institutions.

## 🚀 Features

- 👨‍🎓 **Student management** - Enrollment, profiles, grades
- 👩‍🏫 **Teacher management** - Staff profiles and assignments
- 📊 **Grade tracking** - Report cards and transcripts
- 📅 **Schedule management** - Timetables and exams
- 📱 **Parent portal** - Parent access to student progress

## 🛠️ Tech Stack

- **Frontend**: HTML, JavaScript, CSS
- **Backend**: PHP
- **Database**: MySQL
- **Styling**: Bootstrap, Custom CSS
